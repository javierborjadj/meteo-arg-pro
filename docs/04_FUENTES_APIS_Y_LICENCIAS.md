# 04 — Catálogo de Fuentes de Datos, APIs y Licencias

| Fuente / Servicio | Uso en Meteo-Arg-Pro | Requiere API Key | Licencia / Condición de Uso |
| :--- | :--- | :---: | :--- |
| **Open-Meteo API** (`/v1/ecmwf`, `/v1/gfs`, `/v1/forecast`) | Pronósticos horarios 24/48/72h y estado actual multipunto en AMBA | No (uso no comercial) | CC BY 4.0 — Requiere atribución visible |
| **AviationWeather (NOAA METAR)** | Mediciones físicas horarias en aeropuertos argentinos (SABE, SADM, SAEZ, SADF) | No | Dominio público (US Gov / OACI) |
| **RainViewer Public API** | Barrido de radar meteorológico de precipitación en tiempo real | No | Gratuita con atribución |
| **NASA GIBS WMTS** | Imágenes satelitales MODIS / GOES sobre Sudamérica | No | Datos abiertos NASA Earthdata |
| **NASA FIRMS API** | Detección de anomalías térmicas e incendios activos (VIIRS 375m / MODIS 1km) | Sí (`MAP_KEY` gratuita por email) | Datos abiertos NASA (citar fuente) |
| **Esri ArcGIS Online Tiles** | Mapa base oscuro + etiquetas de ciudades del AMBA | No | Uso con atribución en mapa |
| **SMN Argentina / INMET Brasil** | Referencia oficial nacional y monitoreo satelital regional Sudamérica | No | Datos públicos gubernamentales |
